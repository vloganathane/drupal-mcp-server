# Maintainers

## Current Maintainers

| Name | Role | GitHub | Responsibilities |
|------|------|--------|------------------|
| Drupal MCP Team | Lead Maintainer | @drupal-mcp-team | Project direction, releases, security |

## Roles

### Lead Maintainer
- Sets project vision and roadmap
- Manages releases and versioning
- Handles security incidents
- Merges PRs after review

### Maintainer
- Reviews and merges PRs
- Triages issues
- Maintains documentation
- Participates in architectural decisions

### Contributor
- Submits PRs and issues
- Participates in discussions
- Does not have merge access

## Becoming a Maintainer

1. Contribute consistently for 3+ months
2. Demonstrate expertise in MCP protocol or Drupal
3. Review PRs from other contributors
4. Be nominated by an existing maintainer

## Decision Making

- Consensus preferred for most decisions
- Lead maintainer has tie-breaking authority
- Major changes require 2+ maintainer approval
- Security fixes can be merged by single maintainer with post-merge review
