# Drupal MCP Server API Reference

FastMCP server with 35+ tools across 6 categories.

- Analysis (6): `analyze_d7_site`, `analyze_d9_site`
- Migration (7): `generate_migration_yaml`, `run_migration_test`
- Content (7): `clean_nodes_ai`, `bulk_update_nodes`
- Config (5): `export_config`, `import_config`, `diff_config`
- DevOps (6): `drush_command`, `ddev_start`, `backup_database`
- AI (4): `ai_analyze_content_quality`, `ai_translate_content`

Transport: stdio (default), StreamableHTTP (optional)
