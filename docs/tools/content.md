# Content Tools

## Node CRUD

| Tool | Description |
|------|-------------|
| `create_node` | Create a node with specified fields |
| `get_node` | Get a node by ID with optional includes |
| `update_node` | Update a node's fields |
| `delete_node` | Delete a node |
| `query_nodes` | Query nodes with filters and pagination |

## Media

| Tool | Description |
|------|-------------|
| `upload_media` | Upload a file to the media library |
| `create_media` | Create media from a remote URL |

## Bulk Operations

| Tool | Description |
|------|-------------|
| `bulk_update_nodes` | Update multiple nodes matching filters |
| `bulk_update_aliases` | Bulk URL alias generation |
| `clean_nodes_ai` | AI-powered duplicate detection and cleanup |

## Analysis

| Tool | Description |
|------|-------------|
| `analyze_content_quality` | AI-powered content quality analysis |
| `generate_test_content` | Generate test content for a bundle |
| `fix_media_references` | Find and report broken media references |
