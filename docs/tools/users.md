# User Tools

## User CRUD

| Tool | Description |
|------|-------------|
| `create_user` | Create a new user account |
| `get_user` | Get a user by ID |
| `get_user_by_email` | Get a user by email address |
| `update_user` | Update user fields |
| `delete_user` | Delete a user account |
| `list_users` | List users with filters and pagination |

## Roles & Permissions

| Tool | Description |
|------|-------------|
| `assign_role` | Assign a role to a user |
| `remove_role` | Remove a role from a user |
| `list_roles` | List all available roles |
| `get_user_roles` | Get roles assigned to a user |

## Status

| Tool | Description |
|------|-------------|
| `block_user` | Block a user account |
| `unblock_user` | Unblock a user account |
